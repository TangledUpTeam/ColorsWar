## ⚙️ AI 파라미터 조절

**위치**: `persona_service.py` 73-83번째, 144-154번째 줄

```python
response = requests.post(
    f"{self.ollama_url}/api/generate",
    json={
        "model": self.model,
        "prompt": full_prompt,
        "stream": False,
        "options": {
            "temperature": 0.8,      # ← 창의성 (0.0-2.0)
            "num_predict": 300       # ← 최대 토큰 수
        }
    },
    timeout=60                       # ← 타임아웃 (초)
)
```

### Temperature 조절
- `0.1-0.3`: 매우 일관적, 예측 가능 (논리적)
- `0.5-0.8`: 균형잡힘 (기본값)
- `1.0-1.5`: 창의적, 다양한 표현
- `1.5-2.0`: 매우 창의적, 예측 불가

### num_predict 조절
- `100-200`: 짧은 응답
- `300`: 기본값
- `500-800`: 긴 응답
- `1000+`: 매우 긴 응답 (느림)
