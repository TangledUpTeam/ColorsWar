## 핵심 기능

### 1. 댓글 분석 파이프라인
```
입력 → 키워드 필터링 → 키워드 추출 → 1차 분류 → 재분류 → 학습 저장
```

### 2. 재분류 로직
- 판단불가/중도 댓글을 좌파 또는 우파로 강제 분류
- OpenAI API로 정확한 분류 시도
- 실패 시 키워드 기반 휴리스틱 사용
- 재분류 여부를 UI에 표시

### 3. 학습 데이터 누적
- 메모리 기반 저장 (`TRAINING_DATA` 딕셔너리)
- 서버 실행 중 계속 누적
- 여러 영상의 댓글을 순차적으로 학습 가능
- 실시간 누적 현황 표시

### 4. AI 페르소나 토론
- 좌파 페르소나: 진보/복지/평등 강조
- 우파 페르소나: 시장/안보/전통 강조
- 각 페르소나는 학습된 댓글을 시스템 프롬프트에 포함
- 3-5 라운드 실시간 채팅 형식 토론
- 자동으로 번갈아가며 발언 및 반박

## 실행 방법

```bash
# 1. 패키지 설치
pip install fastapi uvicorn openai requests

# 2. OpenAI API 키 설정 (.env 파일)
OPENAI_API_KEY=sk-your-api-key-here

# 3. 서버 실행
cd test
python app_battle.py

# 4. 브라우저 접속
http://localhost:5000
```

## 주요 특징

### 데이터 지속성
- 메모리에 저장 (서버 재시작 시 초기화)
- 실행 중에는 무한정 누적 가능
- 여러 영상 댓글을 순차적으로 학습

### 자동 워크플로우
1. 사용자가 "분석 시작" 버튼 클릭
2. 자동으로 분석 → 재분류 → 학습 저장
3. 자동으로 AI 페르소나 토론 시작
4. 결과를 실시간으로 화면에 표시

### UI/UX
- 단계별 결과를 접을 수 있는 섹션으로 표시
- 좌파(빨강), 우파(파랑) 색상 코딩
- 재분류된 댓글 별도 표시
- 토론 메시지 애니메이션 효과
- 모바일 반응형 디자인

## 기술 스택

- **Backend**: FastAPI, Python 3.12
- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **AI**: OpenAI GPT-4o-mini
- **Server**: Uvicorn ASGI
- **Testing**: Requests, Python unittest

## 알려진 제한사항

1. 학습 데이터는 메모리에만 저장 (재시작 시 초기화)
2. OpenAI API 키 필요 (토론 및 재분류 기능)
3. Windows 콘솔 인코딩 문제 (UTF-8 처리로 해결)
4. 백엔드 모듈 의존성 (Mock 클래스로 대체 가능)
