# 🎭 색깔전쟁 - AI 페르소나 배틀 시스템

## 🚀 바로 시작하기 (완전 무료!)

### 1️⃣ Ollama 설치 (무료 AI 모델)

```bash
# 1. Ollama 다운로드 및 설치
# https://ollama.com/download

# 2. 모델 다운로드 (한국어 지원)
ollama pull llama3.2

# 완료! Ollama는 자동으로 백그라운드에서 실행됩니다.
```

> 💡 **완전 무료!** OpenAI API 키 불필요  
> 📖 자세한 설치 가이드: `OLLAMA_SETUP.md`

### 2️⃣ 서버 실행

```bash
# 방법 1: Python으로 직접 실행 (개발 모드, 자동 재시작)
python app_battle.py

# 방법 2: uvicorn으로 실행 (권장)
uvicorn app_battle:app --host 0.0.0.0 --port 5000 --reload

# 방법 3: 백그라운드 실행
uvicorn app_battle:app --host 0.0.0.0 --port 5000 &
```

### 3️⃣ 브라우저 열기

```
http://localhost:5000
```

### 4️⃣ 테스트

1. 기본 데이터가 이미 입력되어 있습니다
2. "댓글 분석 및 학습 시작" 버튼 클릭
3. 자동으로 분석 → 재분류 → 학습 → AI 토론 진행
4. 결과 확인!

### 시스템 흐름

```
1. 댓글 입력
   ↓
2. 키워드 필터링
   ↓
3. 키워드 추출
   ↓
4. 정치 성향 1차 분류
   ↓
5. 판단불가/중도 → 좌/우 재분류 ⭐
   ↓
6. 학습 데이터 메모리 저장 ⭐
   ↓
7. AI 페르소나 토론 자동 시작 ⭐
```

### 핵심 특징

✅ **자동 재분류**: 판단불가/중도 댓글을 좌파 또는 우파로 강제 분류
✅ **학습 데이터 누적**: 여러 영상의 댓글을 계속 누적 (서버 실행 중)
✅ **AI 페르소나 토론**: 학습된 댓글을 바탕으로 좌/우파가 토론
✅ **실시간 UI**: 토론 과정을 실시간 애니메이션으로 표시

### API 테스트

## 🔧 문제 해결

### "백엔드 모듈을 찾을 수 없습니다"

→ 정상입니다! Mock 클래스가 자동으로 사용됩니다.

### "connection refused" 오류

→ Ollama가 실행 중인지 확인:
```bash
ollama serve
```

### 토론이 시작되지 않음

→ 좌파와 우파 댓글이 각각 최소 1개 이상 필요합니다.

### AI 응답이 느리거나 이상함

→ 더 나은 모델 사용:
```bash
ollama pull qwen2.5  # 한국어 최적화
```

## 🎯 사용 예시

### 1. 기본 사용

```

3. "댓글 분석 및 학습 시작" 클릭

```

### 2. 여러 영상 누적 학습

```
1. 첫 번째 영상 댓글 입력 → 분석
2. 두 번째 영상 댓글 입력 → 분석
3. 세 번째 영상 댓글 입력 → 분석
→ 학습 데이터가 계속 누적됨!
→ 토론이 점점 더 풍부해짐!
```

### 3. 커스텀 토론 주제

현재는 "현재 정부 정책"이 기본값입니다.
API를 직접 호출하여 주제를 변경할 수 있습니다:

```python
import requests

requests.post("http://localhost:5000/api/battle/start-debate", json={
    "topic": "환경 정책",
    "rounds": 3
})
```

## 💡 팁

1. **좌/우 균형**: 댓글 데이터가 한쪽으로 치우치면 토론이 진행되지 않습니다.
2. **완전 무료**: Ollama는 로컬에서 실행되어 비용이 전혀 없습니다!
3. **학습 누적**: 서버를 계속 실행하면 데이터가 누적됩니다.
4. **데이터 초기화**: 서버를 재시작하면 학습 데이터가 초기화됩니다.
5. **모델 선택**: 한국어 품질을 높이려면 `qwen2.5` 모델 추천!
